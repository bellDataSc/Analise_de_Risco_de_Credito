# Data

Esta pasta contém os datasets utilizados no projeto de Análise de Risco de Crédito.

## Estrutura

- `raw/` - Dados brutos originais
- `processed/` - Dados processados e limpos

## Dataset Principal

O dataset utilizado é de **empréstimos hipotecários na Califórnia**, contendo informações sobre:

- Taxa de juros
- Valor do empréstimo
- Renda do solicitante
- Histórico de crédito
- Status do empréstimo (bom risco vs. alto risco)

## Notas

Os dados são desbalanceados, com a maioria dos empréstimos classificados como de bom risco.
